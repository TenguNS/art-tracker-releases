# Privacy Policy — Art Tracker

**Developed by Berserk** · Last updated: July 6, 2026

*English · Русский ниже · 日本語は下記*

## English

Art Tracker is built privacy-first and works fully offline on your computer.

- **No data collection.** The app does not collect, store or transmit personal data, telemetry or analytics of any kind.
- **Everything stays local.** All statistics (working time, save events, file names, layer counts) are stored only on your computer, in the `%APPDATA%\ArtTracker` folder, and never leave it.
- **No screenshots, no keylogging.** The app only reads the title of the active window and file-save events of your own work files.
- **No accounts, no ads, no third-party SDKs.**
- **Network access.** The only network request the app may make is an update check: it downloads a small version file from GitHub. This request contains no personal data. Without the update check the app works fully offline.
- **Data deletion.** Uninstall the app and delete the `%APPDATA%\ArtTracker` folder — nothing is stored anywhere else.

**Contact:** https://github.com/TenguNS/art-tracker-releases/issues

## Русский

Art Tracker создан по принципу «приватность прежде всего» и работает полностью локально.

- **Мы не собираем данные.** Приложение не собирает, не хранит и не передаёт персональные данные, телеметрию или аналитику.
- **Всё хранится у вас.** Вся статистика (время работы, сохранения, имена файлов, число слоёв) лежит только на вашем компьютере в папке `%APPDATA%\ArtTracker` и никуда не отправляется.
- **Никаких скриншотов и кейлоггинга.** Приложение видит только заголовок активного окна и события сохранения ваших рабочих файлов.
- **Нет аккаунтов, рекламы и сторонних SDK.**
- **Сеть.** Единственный возможный сетевой запрос — проверка обновлений: приложение скачивает с GitHub небольшой файл с номером версии. Запрос не содержит персональных данных. Без проверки обновлений приложение полностью работает офлайн.
- **Удаление данных:** удалите приложение и папку `%APPDATA%\ArtTracker` — больше нигде ничего не хранится.

**Связь:** https://github.com/TenguNS/art-tracker-releases/issues

## 日本語

Art Tracker はプライバシー第一で設計され、完全にローカルで動作します。

- **データ収集なし。** 個人データ、テレメトリ、分析情報を収集・保存・送信することは一切ありません。
- **すべてローカル保存。** 統計（作業時間、保存回数、ファイル名、レイヤー数）は `%APPDATA%\ArtTracker` フォルダにのみ保存され、外部に送信されることはありません。
- **スクリーンショットもキーロギングもなし。** アプリが参照するのは、アクティブウィンドウのタイトルと作業ファイルの保存イベントのみです。
- **アカウント・広告・サードパーティSDKなし。**
- **ネットワーク。** 唯一の通信はアップデート確認（GitHub からバージョン情報ファイルの取得）で、個人データは含まれません。
- **データ削除:** アプリをアンインストールし、`%APPDATA%\ArtTracker` フォルダを削除してください。
